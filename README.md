# AI Powered Feedback Analyzer Demo

This example demonstrates a simple web-based internal tool that simulates AI capabilities, aligning with the concept of 'No-code/Low-code Internal Tools with AI'. Users can input text (e.g., customer feedback) and select an AI task like sentiment analysis, summarization, or keyword extraction. The AI processing is simulated using basic JavaScript logic to illustrate how such features might appear in a low-code platform without requiring actual complex AI models or external API keys.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
